
# Beyond the Family: How Neighborhood Poverty Shapes Academic Outcomes Across the US

## Overview
This project examines neighborhood poverty and family income as predictors of academic achievement, using SEDA (Stanford Education Data Archive) data.

## Contents
- `Presentation.pptx` — Presentation of research findings
- `Neighborhood Poverty vs. Family Income as Predictors of Academic Outcomes.Rmd` — analysis source code (R Markdown)
- `Neighborhood Poverty vs. Family Income as Predictors of Academic Outcomes.html` (and `.pdf`) — knitted output of the analysis
- `Beyond the Family_ How Neighborhood Poverty Academic Outcomes Across US Final.pdf` — final written report
- `data/` — dataset(s) used in the analysis

## How to Reproduce
1. Open the `.Rmd` file in RStudio
2. Ensure required packages are installed (list them if you remember, e.g. `tidyverse`, `lme4`, etc.)
3. Knit the document to reproduce the analysis and output

## Key Findings
Neighborhood poverty is a powerful, independent predictor of academic outcomes. It matters as much as a family's income. It operates above and beyond family income. Where a child lives shapes their educational trajectory in ways that no amount of individual family effort can fully overcome.
